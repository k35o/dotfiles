# シークレット（fnox）

`NODE_AUTH_TOKEN`（npm / GitHub Packages 認証）などの秘密は環境変数に常駐していない。
秘密が必要なコマンドは fnox MCP の exec ツール経由で実行する。

- 例: exec ツールに `["pnpm", "install"]`
- ターミナルから直接叩く場合: `fnox exec -- <command>`

# コードのコメント

コードを書くときコメントは最小限にする。デフォルトはコメント無し。

- 自明なコメント（コードを読めば分かること）は書かない。`// ユーザーを取得` のような説明は不要。
- コメントは「何を」ではなく「なぜ」を説明する必要がある箇所だけに限定する（非自明な意図、回避策、ハマりどころ）。
- セクション区切りや装飾的なコメント（`// ---- helpers ----` 等）は付けない。
- JSDoc/docstring は公開APIなど本当に必要なときだけ。
- 既存ファイルを編集するときは、その周辺のコメント密度に合わせる。
