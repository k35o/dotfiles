# Skill Creator

作成・改善の手順、書き方ガイド、評価ツール（スキルあり/なしのベンチマーク、descriptionのトリガー精度最適化）は、Anthropic公式の `anthropic-skills:skill-creator` を呼び出してそれに従う（Claude Codeに標準同梱・自動更新）。

以下は公式ガイドへのk8o固有の追加方針。重複・競合したらこちらを優先する:

- 個人スキルは `~/.agents/skills/<スキル名>/` に置く（`~/.claude/skills` はここへのシンボリックリンク）
- description・本文とも日本語で書く。descriptionには実際に使う日本語の言い回し（「〜して」「〜したい」等）をトリガーとして含める
- スキルはルール集ではなく軽量なガイド。細かいルールを網羅するより判断基準を短く示し、本当に重要な領域だけ詳細に指定する
- Claudeが既に知っていることは書かない。Claudeが持っていない手続き的知識・チーム固有の意見・落とし穴だけを書く
- 長い散文の仕様より、実コード・テスト・実例への参照の方が忠実に伝わる
- モデルの世代が上がったら、モデルが自力でできるようになった指示を削ってシンプルに保つ
- README.md・CHANGELOG.md などの補助ドキュメントは含めない。スキルはエージェントが仕事をするための情報だけを持つ
- 参照の深さは1段階まで。全ての参照ファイルはSKILL.mdから直接リンクする
