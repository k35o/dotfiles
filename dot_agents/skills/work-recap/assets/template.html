2026-01-01 repo-name / branch-name

TL;DR

何をどう変えたかの要約を2〜4文の地の文で。背景（なぜこの作業をしたか）から書き起こし、読み手がこの段落だけで全体像を掴めるようにする。

変更点

diffの行をクリックするとコメントを書けます。右下のトレイからまとめてコピーして、そのままエージェントに貼り付けてください。

変更のタイトル（何がどうなったか）

この変更が何をしたかを2〜4文の地の文で。どのファイルのどの部分に効くのか、挙動がどう変わるのかを、diffを読まなくても分かるように書く。

なぜこの変更を選んだ理由。検討した制約・トレードオフも文章で書く。
path/to/file.css
.btn-primary {
- background: #2563eb;
+ background: #0d9488;
}

このハンク（まとまり）が何をしているかの説明。ハンクが複数あるときは diff + hunk-note のペアを繰り返す。

UI変更

画面・コンポーネント名

どこがどう変わったかを地の文で。スクリーンショットだけで伝わらない差分（挙動・状態・遷移）はここで補足する。

要判断・確認したいこと

判断が必要な論点のタイトル

何が論点なのか、なぜ判断が分かれるのかを1〜2文で説明してから選択肢を並べる。

  • 暫定採用選択肢A — 選んだ理由を1行で
  • 選択肢B — 見送った理由を1行で

確認したいこと: ユーザーに何を判断・確認してほしいかを疑問形で明確に。
