# 観点1: 日本語の文章ルール（詳細）

日本語の文章ルールを、AIが文意を読んで判定する。

> **精度の注意**: 表記ゆれ・同義語・ら抜き・誤用などは本来は形態素解析で検出するもの。AI判定では取りこぼしや過検出があり得るので、**自信のある箇所のみ指摘**し、断定を避ける。微妙なものは「候補」として挙げる。読点数・連続漢字・文体混在のような客観ルールは、SKILL本体の機械的補助コマンドで先に数えてから判断する。

| ルール        | 内容                                                                                  | NG例 → OK例                                                       |
| ------------- | ------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| 文体統一      | 「である」調と「ですます」調を混在させない                                            | これは重要です。注意すべきである。 → …注意すべきです。            |
| 文末句点      | 段落・箇条書きで句点（。）の有無を混在させない（文末絵文字は許容）                    | りんごを買う。/ バナナを買う → …バナナを買う。                    |
| 読点の数      | 一文の読点（、）は最大3つ。多ければ文を分ける                                         | （読点4つ以上の一文）→ 文を分割                                   |
| 連続漢字      | 漢字が7文字以上連続する熟語は読みにくいので開く                                       | 技術的特異点到達可能性評価 → 技術的特異点に到達できる可能性の評価 |
| 二重否定      | 「〜ないことはない」などの回りくどい二重否定を避ける                                  | 使えないわけではない → 使える                                     |
| 冗長表現      | 「することができる」→「できる」など不要に長い言い回しを削る                           | 変更することができます → 変更できます                             |
| ら抜き言葉    | 「見れる/食べれる」などのら抜きを避ける                                               | 起きれる → 起きられる                                             |
| さ入れ言葉    | 「読まさせて」など不要な「さ」を入れない                                              | 読まさせていただく → 読ませていただく                             |
| 接続詞の連続  | 近接する文で同じ接続詞（「しかし」など）を繰り返さない                                | しかし…。しかし…。 → しかし…。一方で…。                           |
| 形式名詞      | 形式名詞はひらがなで書く                                                              | 実行する事が出来る → 実行することができる                         |
| 副詞          | 副詞はひらがなで書く                                                                  | 既に殆ど → すでにほとんど                                         |
| 補助動詞      | 補助動詞はひらがなで書く                                                              | 確認して下さい / 見て頂く → 確認してください / 見ていただく       |
| 表記ゆれ      | 同一文書内で同じ語の表記を統一する                                                    | サーバ と サーバー の混在 → どちらかに統一                        |
| 同義語の統一  | 同じ意味で別の語を混在させない                                                        | 取り消す と キャンセル → どちらかに統一                           |
| 誤用・慣用句  | 慣用句や助詞の誤用を避ける                                                            | 采配を振るう → 采配を振る                                         |
| ユーザー辞書  | 「シュミレーション/メモリー/コンピューター」→「シミュレーション/メモリ/コンピュータ」 | メモリーとコンピューター → メモリとコンピュータ                   |
| 半角カナ      | 半角カタカナを使わない（全角に統一）                                                  | ﾃｽﾄ → テスト                                                      |
| 全角/半角英字 | 全角英字と半角英字を混在させない（半角に統一）                                        | ＨＴＭＬとCSS → HTMLとCSS                                         |
