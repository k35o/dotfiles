# 観点2: AI Slop・LLMっぽい言い回し（詳細）

**一次担当**: 語句レベルの定型表現（一文単体で判定できるもの）。文書全体を通した修辞の量・語りの一貫性は観点6が担当する。

AIが書いた痕跡が残る定型表現を排除する。

> **太字について**: 一般の文書では強調や初出用語の太字は使ってよい。ここで弾くのは**AI的な機械的な太字**（中身のない強調・ラベル型リスト）だけ。意味のある太字まで否定しない。

| 観点                | 内容                                                                                             | NG例 → OK例                                                            |
| ------------------- | ------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------- |
| 機械的な強調の太字  | 中身のない強調の太字を入れない                                                                   | これは**非常に**重要です → これは重要です                              |
| ラベル型リスト      | 「`**ラベル**: 説明`」型の機械的な太字プレフィックスを使わない                                   | - **重要**: … → - 重要な点として…                                      |
| 絵文字マーカー      | ✅❌💡などを箇条書きの先頭マーカーに使わない                                                     | - ✅ 完了した項目 → - 完了した項目                                     |
| 誇張表現            | 「革命的」「究極の」「ゲームチェンジャー」「世界初」「完全に解決」などの大げさな言い回しを避ける | 革命的な技術で業界を変えます → 効果的な技術で…                         |
| コロン継続          | 「説明します:」のように述語に続けてコロン＋リスト/コードを置かない                               | 説明します:（改行）- 項目 → 説明の内容は次のとおりです。（改行）- 項目 |
| 定型の前置き/まとめ | 「いかがでしたでしょうか」「まず最初に」などの空疎な決まり文句を避ける                           | まず最初に → 最初に                                                    |
| 中身のない一般論    | 「〜は非常に重要です」だけで具体がない段落を避け、具体例・コード・理由を伴わせる                 | 抽象論だけの段落 → 具体例や理由を補う                                  |

## LLMっぽい言い回し（特に避ける）

AI生成文に出やすい定型句。見つけたら、姿勢の宣言や空疎な形容ではなく**具体を述べる文**に書き換える。

- 予告・総括: 「重要なのは〜である」「本記事/本章では〜を扱う」「ここでは〜について見ていく」「まとめると」「要するに」「〜に他ならない」（予告せず本題を書く）
- 姿勢だけの宣言: 「正面から扱う」「正面から向き合う」（何をどう書くかが無い）
- 空虚な形容: 「不可欠」「核心的」「鍵となる」「多角的」「包括的」（中身の説明なしに使わない）
- 空虚な動詞: 「掘り下げる」「言語化する」「（軽く）触れる」（何をどう書いたか示さない）
- 接続の型の連打: 「において」「という側面から」「さらに」「また」の多用
- 弱い緩和: 「と言えるだろう」（根拠が無いなら削る。推量・仮定・認識を表すなら残す）、「非常に」「極めて」の多用

NG例: 「本記事では〇〇の理論を正面から扱う。多角的に分析すると、重要なのは〜である」
OK例: 「本記事では〇〇の理論を扱う。評価の核心は、正しさを誰が知っているかにある」

> **慣例的な節見出しは許容**: 「はじめに」「おわりに」「まとめ」のような定型の節見出しは、媒体のハウススタイルとして許容する（観点4の「情報量ゼロの見出し」では弾かない）。弾くのは本文中の空疎な前置き（「まず最初に」等）だけ。媒体固有の規約が優先する。
